# ร่างราคาอ้างอิงต่อจุด (ยังไม่อนุมัติ)

รวบรวมวันที่ 10 พฤศจิกายน 2569 จากเอกสารทางการและคำแถลงของ กทม. เพื่อให้ผู้ดูแลตรวจก่อนบันทึกเป็น cost assumption ในระบบ **ยังไม่มีรายการใดถูกนำเข้าหรืออนุมัติ** ตัวเลขต่อจุดในคอลัมน์ "ร่างต่อจุด" เป็นการคำนวณจากเอกสาร ผู้ดูแลต้องยืนยันขอบเขตงานและปรับตามราคาปีปัจจุบันก่อนใช้

ระบบรับเฉพาะต้นทุนแบบ `fixed_per_site` ที่มี `evidence_url`, เวอร์ชัน และวันที่มีผล และต้องผูกกับประเภทโครงการเดียวกัน (ดู [cost-evidence-sources.md](cost-evidence-sources.md))

## สรุป

| ประเภทโครงการ (ระบบ) | ร่างต่อจุด | ฐานจากเอกสาร | ความหนักแน่นของหลักฐาน |
|---|---|---|---|
| ปลูกต้นไม้ `tree_planting` | **~800 บาท/ต้น** (ไม้ขนาด Ø 2") หรือ **~9,200 บาท/ต้น** (ไม้ใหญ่ Ø 6") | ราคากลาง สนข.ตลิ่งชัน 13 มี.ค. 2567 | ดี: เอกสารราคากลางทางการ (แบบ บก.06) แต่เป็นราคาปี 2567 และเป็นงานจัดซื้อพร้อมปลูก ไม่รวมดูแลระยะยาว |
| โครงสร้างบังแดด `public_shade_structure` | **~230,000 บาท/หลัง** (2.3×3 ม.) | ศาลาที่พักผู้โดยสาร Type M ของ สจส. | ปานกลาง: ผอ.สจส. แถลงเป็นราคาประมาณ ยังไม่ได้เห็น BOQ |
| จุดพักคลายร้อน `cooling_rest_area` | **~320,000 บาท/หลัง** (2.3×6 ม., 6 ที่นั่ง) | ศาลาที่พักผู้โดยสาร Type L ของ สจส. | ปานกลาง: เหมือนข้างบน และศาลารถเมล์ยังไม่ใช่จุดพักคลายร้อนโดยตรง (ไม่มีพัดลม/น้ำดื่ม) |
| ทางเดินร่มเงา `shaded_walkway` | **~12,800 บาท/เมตร** (≈1.28 ล้านบาทต่อช่วง 100 ม.) | Covered walkway สาทรใต้ 1.6 กม. งบ 20,523,000 บาท | ปานกลาง: งบรวมจากโฆษก กทม. ต้องกำหนดเองว่า "1 จุด" ยาวกี่เมตร |
| พื้นผิวสะท้อนความร้อน `reflective_surface` | **ยังไม่มีราคาทางการ** | — | ไม่พอ: พบเพียงราคาผู้รับเหมาเอกชน ~450 บาท/ตร.ม. ไม่ควรใช้ |

## รายละเอียดและที่มา

### 1. ปลูกต้นไม้: ราคากลางสำนักงานเขตตลิ่งชัน
- เอกสาร: [รายละเอียดคุณลักษณะเฉพาะและราคากลาง งานจัดซื้อวัสดุอุปกรณ์ในการปลูกและบำรุงรักษาต้นไม้](https://webportal.bangkok.go.th/public/user_files_editor/58/2567/jobs/jobs130367_02.pdf) วันที่กำหนดราคากลาง 13 มีนาคม 2567 วงเงิน 1,200,000 บาท
- รายการที่ใช้ (ผู้ขายปลูกให้ตามแบบ ราคารวมภาษีและค่าขนส่ง รับประกัน 60 วัน):
  - ต้นเสลา Ø ≥ 2" สูง 2.5 ม. **650 บาท/ต้น**
  - ต้นกระทิง Ø 6" สูง ≥ 4.5 ม. **9,000 บาท/ต้น**
  - ดินผสม ถุง 20 กก. **45 บาท** และไม้หลักค้ำยัน **35–42 บาท/ท่อน** (ในเอกสารใช้ 3 ท่อนต่อต้น)
- วิธีคิดร่าง: ต้นไม้ + ดิน 1 ถุง + ไม้ค้ำ 3 ท่อน → Ø 2" ≈ 650 + 45 + 105 = **800 บาท**, Ø 6" ≈ 9,000 + 45 + 126 = **9,171 บาท**
- ไม่รวม: ขุดหลุมขนาดใหญ่ ระบบน้ำ ตะแกรงป้องกันราก ค่ารดน้ำและดูแลหลัง 60 วัน อัตราการรอดตาย

### 2–3. โครงสร้างบังแดด / จุดพักคลายร้อน: ศาลาที่พักผู้โดยสาร สจส.
- แหล่ง: คำแถลงของ ผอ.สำนักการจราจรและขนส่ง กทม. 4 ก.พ. 2568 ([ข่าวสด](https://www.khaosod.co.th/breaking-news/news_9619999))
  - Type M 2.3×3 ม. 3 ที่นั่ง **ประมาณ 230,000 บาท/หลัง**
  - Type L 2.3×6 ม. 6 ที่นั่ง **ประมาณ 320,000 บาท/หลัง**
- ราคาครอบคลุม: รื้อย้ายสาธารณูปโภค ฐานรากคอนกรีตเสริมเหล็ก โครงเหล็ก หลังคา metal sheet รางน้ำ ม้านั่ง ไฟแสงสว่าง และการต่อไฟกับ กฟน.; ผอ.สจส. ระบุว่าราคาหลัง e-bidding ต่ำลงอีก
- ที่ควรหาเพิ่ม: ประกาศราคากลาง/ผลประกวดราคาใน e-GP ของโครงการ "ก่อสร้างศาลาที่พักผู้โดยสารรถประจำทาง" (เช่น กลุ่มกรุงเทพกลาง 22 หลัง) หน้า tracking ของ กทม. ต้องล็อกอิน จึงยังไม่ได้ยืนยันตัวเลขจากเอกสารต้นฉบับ

### 4. ทางเดินร่มเงา: Covered walkway สาทรใต้
- แหล่ง: โฆษก กทม. 26 ก.พ. 2568 ([ผู้จัดการออนไลน์](https://mgronline.com/onlinesection/detail/9680000019003)) และ [ศูนย์ต่อต้านข่าวปลอม (ตรวจสอบโดยสำนักงานประชาสัมพันธ์ กทม.)](https://www.antifakenewscenter.com/%E0%B8%99%E0%B9%82%E0%B8%A2%E0%B8%9A%E0%B8%B2%E0%B8%A2%E0%B8%A3%E0%B8%B1%E0%B8%90%E0%B8%9A%E0%B8%B2%E0%B8%A5-%E0%B8%82%E0%B9%88%E0%B8%B2%E0%B8%A7%E0%B8%AA%E0%B8%B2%E0%B8%A3/%E0%B8%81%E0%B8%97%E0%B8%A1-%E0%B9%80%E0%B8%95%E0%B8%A3%E0%B8%B5%E0%B8%A2%E0%B8%A1%E0%B8%88%E0%B8%B1%E0%B8%94%E0%B8%97%E0%B8%B3%E0%B8%AB%E0%B8%A5%E0%B8%B1%E0%B8%87%E0%B8%84%E0%B8%B2%E0%B8%84%E0%B8%A5%E0%B8%B8%E0%B8%A1%E0%B8%97%E0%B8%B2%E0%B8%87%E0%B9%80%E0%B8%97%E0%B9%89%E0%B8%B2-%E0%B8%99%E0%B8%B3%E0%B8%A3%E0%B9%88%E0%B8%AD%E0%B8%87%E0%B8%96%E0%B8%99%E0%B8%99%E0%B8%AA%E0%B8%B2%E0%B8%97%E0%B8%A3%E0%B9%83%E0%B8%95%E0%B9%89/)
  - ช่วง MRT ลุมพินี–สกายวอล์กช่องนนทรี 1.6 กม. งบประมาณ **20,523,000 บาท** สัญญา 18 ก.ย. 2567–19 มี.ค. 2568 (180 วัน) สำนักการโยธาร่วมกับ UddC
- วิธีคิดร่าง: 20,523,000 ÷ 1,600 ม. ≈ **12,827 บาท/เมตร**
- ข้อควรระวัง: เป็นงบรวมของโครงการนำร่อง ยังไม่ได้เห็นรายการ BOQ ว่ารวมงานใดบ้าง และมีการปรับแบบหลบเสาไฟ ต้องกำหนดความยาวมาตรฐานต่อ "1 จุด" ก่อนใช้

### 5. พื้นผิวสะท้อนความร้อน
- ยังไม่พบราคากลางของหน่วยงานรัฐ ราคาที่พบเป็นของผู้รับเหมาเอกชน (~450 บาท/ตร.ม. ขั้นต่ำ 500 ตร.ม.) ไม่ควรใช้เป็นหลักฐาน
- ที่ควรหาเพิ่ม: บัญชีราคามาตรฐานสิ่งก่อสร้างของ[สำนักงบประมาณ](https://www.bb.go.th/InfoCenter/topic-detail.php?id=18270&mid=280) หรือประกาศ e-GP งาน "ทาสีสะท้อนความร้อน/สีกันความร้อนหลังคา" ของหน่วยงานรัฐ

## ก่อนนำเข้าระบบ
1. ผู้ดูแลตรวจว่าขอบเขตงานในเอกสารตรงกับโครงการที่จะทำในแต่ละจุด
2. ปรับราคาปี 2567–2568 เป็นราคาปัจจุบัน หรือบันทึกปีของราคาไว้ใน assumptions
3. บันทึกผ่านหน้า Evidence Gate ของศูนย์ข้อมูล (ต้องล็อกอินผู้ดูแล) พร้อม `evidence_url` ของเอกสารต้นฉบับ
4. ต้นทุนอย่างเดียวยังไม่พอให้จุดเข้า optimizer: แต่ละจุดต้องมีผลสำรวจพื้นที่ สิทธิ์ในที่ดิน และการตรวจแบบ/การเข้าถึงด้วย

## ผลตรวจทาน (10 พ.ย. 2569)
- ปลูกต้นไม้: ตัวเลขตรงกับ PDF ราคากลางเขตตลิ่งชันทุกบรรทัด (650 / 9,000 / 45 / 35–42 บาท) ใช้ได้ แต่ควรบันทึกว่าเป็นราคาปี 2567
- ศาลา Type M/L: ตรงกับคำแถลง ผอ.สจส. 4 ก.พ. 2568 ยังไม่มี BOQ ต้นฉบับ ควรติดป้ายระดับหลักฐาน "คำแถลงหน่วยงาน"
- ทางเดินร่มเงา: 20,523,000 บาท / 1.6 กม. ตรงกับคำแถลงโฆษก กทม. ต้องกำหนดความยาวต่อจุดก่อนบันทึก
- พื้นผิวสะท้อนความร้อน: ยังไม่ควรบันทึก
- ข้อเสนอ: บันทึก `tree_planting` เป็นรายการแรก เพราะหลักฐานแข็งที่สุด และมีจุดตัวอย่างพร้อมแล้วที่ [site-evidence/vibhaphirom-park.md](site-evidence/vibhaphirom-park.md)
- พื้นผิวสะท้อนความร้อน (ค้นเพิ่ม 10 พ.ย.): ยังไม่พบราคากลางทางการ บทความเอกชนอ้างบัญชีราคากรมโยธาธิการฯ ปี 2568 งานทาสีกระเบื้องหลังคา 28+35 บาท/ตร.ม. แต่ยังไม่ได้ยืนยันกับเอกสารต้นฉบับ และเป็นสีทั่วไปไม่ใช่สีสะท้อนความร้อน ขณะนี้ระบบไม่มี candidate ประเภท `reflective_surface` เลย (มีเพียงปลูกต้นไม้ จุดพักคลายร้อน และโครงสร้างบังแดด รวม 1,482 จุด) จึงยังไม่จำเป็นต้องบันทึกราคานี้
