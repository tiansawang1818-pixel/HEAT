# แหล่งหลักฐานต้นทุนสำหรับผู้รับผิดชอบตรวจ

ตรวจแหล่งสาธารณะวันที่ 7 พฤศจิกายน 2026 ไม่ได้นำราคาในเอกสารมาอนุมัติเป็นต้นทุนต่อจุดในระบบ และไม่ได้รับรองพื้นที่หรือผลลดความร้อนแทนเจ้าของงาน

| แหล่งทางการ | ใช้ช่วยตรวจอะไร | สิ่งที่ยังสรุปไม่ได้ |
|---|---|---|
| [สำนักงบประมาณ: บัญชีราคามาตรฐานสิ่งก่อสร้าง มกราคม 2569](https://www.bb.go.th/InfoCenter/topic-detail.php?id=18270&mid=280) | จุดเริ่มตรวจรายการก่อสร้าง มาตรฐาน/รุ่นเอกสาร และเอกสารแนบของหน่วยงาน | หน้าเผยแพร่ไม่ใช่ BOQ ของหลังคา/ทางเดิน ณ จุดเป้าหมาย ยังไม่ได้ยืนยันรายการหรือราคาต่อพื้นที่ใด |
| [สำนักงานเขตตลิ่งชัน: คุณลักษณะและราคากลางวัสดุปลูก/บำรุงต้นไม้](https://webportal.bangkok.go.th/public/user_files_editor/58/2567/jobs/jobs130367_02.pdf) | ตัวอย่างข้อกำหนดชนิด/ขนาดไม้ จำนวน หน่วย และแหล่งราคาของงานในอดีต เอกสารระบุพื้นที่ดำเนินการของตนเอง | เอกสารปี 2567 ไม่ใช่ราคาปัจจุบันของทั้งกรุงเทพฯ และไม่รวมภาระหน้างานทุกชนิดของ candidate ใหม่ |

สำหรับ tree planting ต้องแยกชนิด/ขนาดต้นไม้ ค่าดิน/หลุมปลูก การขนส่ง ค้ำยัน ระบบน้ำ การรอดตายและการดูแลต่อเนื่อง สำหรับ shade/walkway/rest area ต้องมีแบบ ขนาด พื้นฐานโครงสร้าง การเข้าถึง ระบบไฟ/น้ำถ้ามี และงานบำรุงรักษา ส่วน reflective surfaces ต้องตรวจวัสดุเดิม แสงสะท้อน/ความปลอดภัย และการบำรุงผิวจริง

การประกาศงบรวมของโครงการ หรือมีจำนวนต้นไม้ที่ปลูก ไม่เพียงพอให้หารเป็นต้นทุนต่อจุด ต้องทราบว่างบครอบคลุมอะไร ช่วงราคาวันไหน และสภาพหน้างานใดก่อน ระบบจึงรับเฉพาะ `fixed_per_site` ที่ผู้รับผิดชอบยืนยันพร้อม evidence URL/version และผูกกับโครงการประเภทเดียวกัน ไม่ auto-import หรือ auto-approve ราคาจากผลค้นหา

ข้อมูลดาวเทียม/OSM แสดงความร้อน สิ่งปกคลุมดิน และตำแหน่งที่ควรสำรวจ ไม่ยืนยันสิทธิ์ใช้ที่ดิน โครงสร้างใต้ดิน ระยะร่น การอนุญาต หรือจำนวนผู้ใช้จริง การปลด evidence gate ต้องมีผู้รับผิดชอบสำรวจและยืนยัน site feasibility, land control, design/accessibility review และหลักฐาน benefit เมื่อให้ตัวเลขผู้รับประโยชน์/ผลประโยชน์

สรุปการจัดสรรงบกันเศษบาทโดยปัดขึ้น จำนวนผู้รับประโยชน์เป็นผลรวมรายโครงการที่ยังไม่หักการซ้ำบุคคล/พื้นที่บริการ ช่องที่ไม่มีหลักฐานแสดงไม่ทราบ ไม่แทนด้วยค่าประมาณที่สร้างขึ้น
